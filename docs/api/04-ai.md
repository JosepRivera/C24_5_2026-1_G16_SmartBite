### Asistente conversacional · POST /ai/query

> El dueño hace preguntas sobre su negocio en lenguaje natural. Claude API
> genera el SQL, NestJS lo valida y ejecuta en modo solo lectura, y devuelve
> el resultado con el SQL generado.
> Solo se permiten SELECT. Sentencias con INSERT/UPDATE/DELETE/DROP y similares
> son rechazadas. Los trailing semicolons se normalizan automáticamente.
> Si Claude API no está disponible devuelve `503` sin romper el sistema.

**Autenticación:** Requiere Bearer token
**Roles permitidos:** `OWNER`

---

#### Request body

| Campo      | Tipo   | Requerido | Validación | Descripción                  |
| ---------- | ------ | --------- | ---------- | ---------------------------- |
| `question` | string | ✅         | min 1      | Pregunta en lenguaje natural |

---

#### Ejemplo de request

**Headers**
```
POST /api/v1/ai/query
Authorization: Bearer <token>
Content-Type: application/json
```

**Body**
```json
{
  "question": "Lista los primeros 5 productos con su nombre y precio"
}
```

---

#### Respuesta exitosa · `200 OK`
```json
{
  "data": {
    "sql": "SELECT id, name, price FROM products LIMIT 5",
    "result": [
      {
        "id": "f0feca65-5203-4a60-bb55-1b71fca18e96",
        "name": "Hamburguesa Clásica",
        "price": "1800"
      },
      {
        "id": "e9da7c23-05ff-4176-a8f3-883908636183",
        "name": "Papas Fritas",
        "price": "800"
      }
    ]
  }
}
```

> El campo `sql` muestra la consulta generada por Claude. Útil para depuración.
> Los precios se devuelven como strings (tipo `Decimal` en Postgres).

---

#### Casos de error

| Status | Error               | Causa                                               |
| ------ | ------------------- | --------------------------------------------------- |
| 400    | Bad Request         | Claude generó SQL inválido, con DML o múltiples sentencias |
| 401    | Unauthorized        | Token ausente o inválido                            |
| 403    | Forbidden           | Rol sin permiso                                     |
| 503    | Service Unavailable | Claude API no disponible                            |

### Recomendador de compras · GET /mrp

> Calcula qué insumos comprar y en qué cantidad basándose en la predicción
> de demanda Holt-Winters y el stock actual. La fórmula es:
> `to_order = max(0, ceil(demanda × cantidad_receta) − stock_actual)`.
> Claude API redacta la lista en lenguaje natural (fallback a tabla si no está disponible).

**Autenticación:** Requiere Bearer token
**Roles permitidos:** `OWNER`

---

#### Query parameters

| Parámetro | Tipo | Default | Descripción                           |
| --------- | ---- | ------- | ------------------------------------- |
| `days`    | int  | `3`     | Número de días a proyectar. Máximo: 7 |

---

#### Ejemplo de request

**Headers**
```
GET /api/v1/mrp?days=7
Authorization: Bearer <token>
```

---

#### Respuesta exitosa · `200 OK`
```json
{
  "data": {
    "days": 7,
    "items": [
      {
        "ingredient_id": "423328eb-1ee1-4e4c-b6f3-391d08045e2e",
        "ingredient_name": "Papa",
        "unit": "kg",
        "current_stock": 9.7,
        "needed": 2,
        "to_order": 0
      },
      {
        "ingredient_id": "b23099be-d675-4118-8c64-b7d113511a6e",
        "ingredient_name": "Pan de hamburguesa",
        "unit": "unidad",
        "current_stock": 150,
        "needed": 14,
        "to_order": 0
      }
    ],
    "summary": "Para los próximos 7 días, el stock actual es suficiente para cubrir la demanda estimada."
  }
}
```

> `to_order = 0` significa que el stock actual cubre la demanda proyectada.
> `summary` es redactado por Claude o, si no está disponible, como lista de texto plano.

---

#### Casos de error

| Status | Error        | Causa                    |
| ------ | ------------ | ------------------------ |
| 401    | Unauthorized | Token ausente o inválido |
| 403    | Forbidden    | Rol sin permiso          |

### Plan de producción · GET /production-plans/today

> Devuelve el plan de producción del día actual precalculado por el cron
> job de las 6 am. También disponible justo después de `/regenerate`.

**Autenticación:** Requiere Bearer token
**Roles permitidos:** `OWNER`

---

#### Ejemplo de request

**Headers**
```
GET /api/v1/production-plans/today
Authorization: Bearer <token>
```

---

#### Respuesta exitosa · `200 OK`
```json
{
  "data": {
    "date": "2026-04-18",
    "items": [
      {
        "id": "c7f3a7d7-a2a0-42d9-b23e-0198855f157e",
        "product_id": "89c04027-59c0-4e4e-885e-fab292015dae",
        "product_name": "Hamburguesa Doble",
        "quantity": 1,
        "prediction_source": "holt-winters"
      },
      {
        "id": "c2a2d329-eab5-4d95-b231-ab20f09a8988",
        "product_id": "e9da7c23-05ff-4176-a8f3-883908636183",
        "product_name": "Papas Fritas",
        "quantity": 1,
        "prediction_source": "holt-winters"
      }
    ]
  }
}
```

> `prediction_source` puede ser `holt-winters` o `holt-winters+claude`
> (este último cuando Claude ajustó el multiplicador base).

---

#### Casos de error

| Status | Error        | Causa                                    |
| ------ | ------------ | ---------------------------------------- |
| 401    | Unauthorized | Token ausente o inválido                 |
| 403    | Forbidden    | Rol sin permiso                          |
| 404    | Not Found    | El cron job aún no generó el plan de hoy |

---

### Regenerar plan · POST /production-plans/regenerate

> Regenera manualmente el plan de producción del día actual. Útil si el dueño
> corrigió datos después de las 6 am y quiere actualizar el plan sin esperar
> al día siguiente. El cron job vuelve a ejecutarse de inmediato.

**Autenticación:** Requiere Bearer token
**Roles permitidos:** `OWNER`

---

#### Ejemplo de request

**Headers**
```
POST /api/v1/production-plans/regenerate
Authorization: Bearer <token>
```

---

#### Respuesta exitosa · `200 OK`
```json
{
  "data": {
    "message": "Plan de producción regenerado exitosamente"
  }
}
```

---

#### Casos de error

| Status | Error               | Causa                    |
| ------ | ------------------- | ------------------------ |
| 401    | Unauthorized        | Token ausente o inválido |
| 403    | Forbidden           | Rol sin permiso          |
| 503    | Service Unavailable | Claude API no disponible |
